🍳 Recipe Finder App

Recipe Finder is a modern, responsive web application that allows users to search, explore, and save recipes easily. Users can search by recipe name, browse by categories like Breakfast, Lunch, Dinner, Vegan, or Dessert, and manage their favorite recipes in a personal favorites section.

This project is built using HTML, CSS, and JavaScript, leveraging TheMealDB API for fetching recipe data. It demonstrates dynamic UI updates, DOM manipulation, local storage usage, and responsive design for mobile, tablet, and desktop device.


🚀 Features

Search recipes by name

Filter recipes by category

View recipe images and names

Add recipes to favorites ❤

Remove recipes from favorites ❌

Fully responsive design for mobile, tablet, and desktop


💻 How It Works

1. Search Recipes: Users type a recipe name and click Search, fetching results from TheMealDB API.

2. Display Recipes: Recipes are displayed as cards with images, names, and an Add to Favorites button.

3. Add to Favorites: Recipes are saved in localStorage to persist after page reload.

4. View Favorites: Favorites section shows all saved recipes with an option to remove them.

5. Category Filters: Click a category button to fetch and display recipes from that category.

6. Error Handling: If no recipes are found, a friendly message is displayed.
